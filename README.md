# Blake's Builds

A static site of games, apps, and experiments I'm building with AI. GitHub Pages serves it from the root of the `main` branch. The empty `.nojekyll` file keeps Jekyll from rewriting the pages.

## Games

- [Daisy Counts](games/daisy-counts/) — count 1 to 10 with fun objects
- [Shape Friends](games/shape-friends/) — shapes, colors, and letters

Open `index.html` in a browser, or visit the Pages URL after the `main` branch is published.
